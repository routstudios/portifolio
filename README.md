# ROUT STUDIOS

Portfólio oficial da Rout Studios — um estúdio digital independente criado por Redzzz e ToutCZ.

## Stack

- Next.js + TypeScript
- Tailwind CSS
- Framer Motion

## Desenvolvimento

```bash
npm install
npm run dev
```

## Deploy

O projeto está pronto para importação e deploy na Vercel.
